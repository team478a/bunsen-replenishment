# 架空データによる現場受入キット

実CSV未提供でも現場担当者が一連の操作を試せる準備機能です。通常履歴から分離した試用DBを使います。実CSV接続・業務承認・現場受入完了は未確認です。

## 作成と起動

配布ZIP全体を展開してPowerShellで実行します。日付を実際の試験日に、パスを端末の絶対パスに置き換えてください。

```powershell
& 'C:\Bunsen\BunsenTools.exe' acceptance-kit --dispatch 2026-11-10 --output 'C:\BunsenTrial\受入キット'
& 'C:\Bunsen\BunsenReplenishment.exe' --trial-kit 'C:\BunsenTrial\受入キット'
```

ソース版の起動方法:

```powershell
python -m bunsen.tools acceptance-kit --dispatch 2026-11-10 --output 'C:\BunsenTrial\受入キット'
python -m bunsen --trial-kit 'C:\BunsenTrial\受入キット'
```

指定出荷日の07時以降に操作試験します。本日限定・未来基準日時拒否・朝現物確認・期限・積載・二重割当の検証は解除しません。前日や07時前に朝CSVを使うと停止します。時計変更は不要です。固定日付の自動検証には従来のself-test / demoを使います。

作成は新規フォルダー限定で、DBを開きません。`--trial-kit`と`--data-dir`は同時指定できません。生成失敗時は新規作成したファイルを削除します。強制終了で不完全フォルダーが残った場合は別名で新規作成してください。

## 生成内容

| 内容 | 意味 |
|---|---|
| samples/before_morning | 朝現物在庫を含まない架空CSV |
| samples/morning | 240Pの朝在庫に対して両倉庫各240Pを希望する不足例 |
| samples/multi_lot | L001=144P、L002=96Pの架空ロット例 |
| GUIDE.md | キットの試験日付に対応する操作手順 |
| kit.json | 版、元試験日、移動日数、元サンプル・生成CSVのSHA-256 |
| acceptance-record.json | 人が実結果・根拠を記入する未実施の受入記録 |
| trial-data（初回起動時） | 試用識別、SQLite履歴、帳票。LOCALAPPDATAとは別 |

生成元は同梱の架空サンプル3種類に固定し、任意のCSVを受け付けません。全ての日付・日時・賞味期限を同じ日数だけ移し、数量・換算・相対期限は保持します。確認済み宣言も架空の例で、実在庫を確認した事実にはなりません。実CSVの日付修正や未確認値の補完には使用できません。

起動時に形式・アプリ版の一致、CSV一覧・ハッシュ、試用DBの所在と識別を確認します。版を更新した場合は新しいキットを生成してください。CSV変更・欠損・未知CSVがあればDBを開く前に停止します。受入記録は人が追記できるようハッシュ対象から外します。ハッシュは不整合検出用で、電子署名や故意の改ざん防止・真正性の証明ではありません。キット全体は別パスへ移動できます。

## 履歴と帳票の区別

必ず同じ`--trial-kit`で再起動し、キット内のtrial-data/history.dbで続けてください。画面タイトル・保存先に「架空データ試用・実出荷不可」を表示します。復元履歴から「元の試用データへ戻る」を選ぶと同じキットのDBへ戻ります。

試用区分をDBイベントと発行スナップショットに保存します。識別ファイルを失っても既存の試用DBは試用区分を維持します（キット専用起動は識別欠損自体を拒否）。仮／正式帳票、再出力、バックアップ後の閲覧専用復元にも「架空データの試用帳票 — 実出荷に使用しない」を表示します。試用番号は実際の出荷番号と混ぜません。

これは権限・認証境界ではありません。試用中に実データを取り込まず、帳票・紙・PDF・DB・バックアップを実出荷に使用しないでください。

## 人による結果記入

GUIDE.mdと[現場受入手順](acceptance-test.md)に従います。複数ロット試験は別キットで行い、改訂や履歴を混ぜません。

acceptance-record.jsonに端末、担当者、実施日時、各ケースの実結果と証拠の保存先を記入します。状態は例としてpass / fail / blocked / not_performedを使えます。作成直後は全件not_performed、承認unconfirmedです。自動テストは現場結果を成功に変更しません。現場PC、実プリンター・日本語PDF、実CSV照合、業務設定の責任者確認は別途必要です。

実データ・業務情報・試験証拠・個人情報をコミットしないでください。共有・保存先・保存年限は責任者が決めます。
