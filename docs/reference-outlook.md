# 補充前の14日参考見通し

選択した基準日から14日先までの15日分を、倉庫別・商品別に表示します。目的は4〜7日先の不足リスクの早期発見と、8〜14日先の参考確認です。**予測に基づく算術的な参考値であり、確定在庫・実欠品・出荷指示ではありません。将来の予測精度を保証しません。**

## 使用方法

GUIでは日常操作でCSVを取り込み、対象出荷日を指定し、「14日参考見通し」タブの「取込済データから参考見通しを表示」を押します。対象出荷日を見通しの基準日として使います。当日、1〜3日先、4〜7日先、8〜14日先は、この基準日からの区分です。

不足リスクは赤、確認不能は茶色と文字で表示します。行を選ぶと、確認不能理由、在庫基準日時・輸送中網羅確認日時・予測基準日時、到着する輸送中明細を確認できます。JSONと印刷用HTMLに新規保存でき、HTMLはブラウザーから印刷・PDF保存できます。

```powershell
python -m bunsen.tools outlook C:\input\csv --start 2026-11-10 --output C:\review\reference-outlook.json
```

配布版では`BunsenTools.exe outlook`を使用します。CLIはCSVを読み取るだけで業務DBを開きません。GUIも見通し表示・保存ではDB・補充計算明細・手修正・確認チェックを更新しません。CSV再取込、再計算、対象出荷日変更、履歴再開、保存先DB切替等で画面の参考結果を無効化し、再表示を求めます。

| CLI終了コード | 意味 |
|---|---|
| 0 | 参考計算の必要入力に欠落を検出しなかった。不足リスクがあっても0。正式発行可・業務承認ではない |
| 2 | 一部または全体が確認不能。JSON・HTMLには計算できた日と確認不能理由を保存 |
| 1 | CSV取込不備、日付範囲、保存失敗等。新規レポート出力を停止 |

JSONにはformal_issue_allowed=false、planned_replenishment_included=falseを常に記録します。入力フォルダー内への保存と既存出力の上書きを拒否し、片側出力に失敗した場合は新規作成した出力だけを削除します。出力ファイルを後からデータ取込・発行検証に使い回しません。

## 計算の定義

1. 確認済みのムロオ倉庫在庫を起点とする。
2. 在庫基準日から見通し開始前日までの日次需要予測全量を減算し、その間の確認済み輸送中到着を加算して基準日の始業予測残高を求める。
3. 各日、始業予測残高＋当日到着する確認済み輸送中数量－当日の需要予測＝終業予測残高とする。
4. 終業予測残高が負なら「不足リスク（予測）」と表示する。

輸送中のない日は、在庫基準日時と同じ日時で網羅確認された宣言がある場合に限り、既知の到着数量を0とする。輸送中ファイル・網羅宣言自体の欠損は取込停止で、宣言日時が不一致なら到着数量と残高を確認不能にする。在庫基準日以前の到着が輸送中に残る場合も二重計上疑いとして停止する。

数量は全てP。出荷単位への丸めや出荷日→到着日の配送計算ではなく、既に確認された輸送中レコードの到着日を使用する。安全在庫・補充期間・配送日数を新たに決定せず、乾麺在庫を配分しない。

**仮／正式指示・画面の手修正・乾麺倉庫在庫・未確定の製造／入庫予定・新たな補充案は反映しない。** 当日正式分と翌日計画を連続して割り当てるシミュレーションではない。確定注文を別途加算せず、既存のincluded契約を維持する。

## 確認不能と制約

- 必要予測が欠けた日は、需要予測を0で埋めない。その日以降の始業／終業残高を確認不能とし、後日の予測や輸送中レコードが存在しても残高は自動復旧しない。
- 見通し開始前の予測欠落、在庫基準日が開始日より未来、輸送中の基準不一致等は、当該倉庫・商品の全期間を確認不能にする。他の倉庫・商品まで数値を捨てない。
- 予測基準日が見通し基準日より未来の場合、その予測は使わない。CSVに記載された予測基準日時は引き続き表示する。
- 算術上、在庫基準日の在庫から同日の日次予測全量を差し引く。日内の既消費分との重複、入庫時刻と需要発生順は未確認。同日到着を需要より先に加算する計算で、日内の欠品回避は保証しない。
- 負残高は累積の算術的不足。実欠品や注文繰越・欠品件数を確定せず、KPI実績にも変換しない。
- 実CSV接続・鮮度基準・将来予測精度・業務承認は未確認。サンプルCSVは一部日付しかないため、後半は意図どおり確認不能となる。

CSV構造・必須数値自体の不備は従来どおり取込全体を停止します。本機能の参考表示が成功しても、正式出荷には当日朝の乾麺現物在庫・実ロット・期限・積載・改訂・担当者の再確認を別途必須とします。
