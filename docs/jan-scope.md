# PDF未掲載商品・JAN対象設定（0.7.4）

## 「空欄を0」とPDF未掲載の違い

「ケース・バラの空欄は0」は、PDFに存在する商品行の数量欄だけに適用します。商品自体がPDFにない場合は、その倉庫の在庫を0と断定できません。表では「未掲載」と表示し、保存エラーには倉庫・JAN・品名・集計日を表示します。数量を確認すべき補充対象は、引き続き確認完了まで保存・正式発行を止めます。

TV/非TVの名称から対象を自動判定しません。不要な商品は担当者が明示的に補充対象外へ変更します。対象外は在庫0の意味ではありません。必要な商品を在庫切れだから対象外にする操作ではありません。

## PDF画面から対象外にする

1. 未掲載の不要商品を一覧から選びます。
2. 担当者と「変更・確認根拠」に対象外にする理由を入力します。
3. 「選択JANを補充対象外にする（マスタ更新）」を押します。
4. このJANは神戸・杉戸の両方と今後の補充対象から外れます。残る対象商品の数量確認後に保存します。

対象外設定はマスタへ保存します。毎回同じ未掲載商品を除外する必要はありません。戻す場合はJANマスタ画面を使います。原本に未掲載でも、別途確認した在庫数量と確認根拠を手入力する従来機能も保持します。自動0補完はしません。

## マスタの上書き・対象外・復帰

「管理・その他」→「JAN・倉庫別PLマスタ」で一覧のJANを選ぶと編集できます。値を変更し、理由・担当者を入力して保存すると同じJANを更新します。JANコード自体は選択時に読取専用です。

不要なJANは理由・担当者を入力して「選択JANを対象外にする（削除）」を押します。行は「対象外」として残し、補充計算では使いません。「選択JANを対象に戻す」で復帰できます。対象外の商品の品名やPL数なども編集可能です。過去の指示・登録・変更履歴は消しません。

## CSVの追加更新と置換

CSV画面に2つのモードがあります。

- 追加・更新: CSVの同じJANを上書き更新し、CSVにない既存の補充対象を残します。
- CSVの一覧で置換: CSVに含まれるJANだけを補充対象にします。CSVにない既存JANは対象外へ変更し、登録情報と履歴を保持します。

CSV読取後に対象外となる件数・JAN・品名を確認し、担当者・理由を入力して保存してください。CSVに含めた既存の対象外JANは再び補充対象になります。不備が1行でもあれば、対象外変更を含めて登録全体を停止します。空CSVによる一括消去は行いません。

## 計算・履歴

保存済みの対象外JANはPDF数量・日別予測・共通条件の計算行から除きます。予測CSVの原本は対象外JANを含めて保持・再検証し、product-scope.csvへ除外JAN・理由・担当者・マスタ版を保存します。計算根拠と帳票にも対象外設定を明示します。対象商品には両倉庫の在庫・日別予測・PL条件が引き続き必要です。

対象設定を変えた古い計算・配送計画は正式確定できません。再取込・再計算してください。旧指示は保存した当時の対象で再出力できます。バックアップ・復元にも対象設定を含め、復元履歴は閲覧専用です。
