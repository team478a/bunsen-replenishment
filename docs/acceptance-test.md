# 現場受入試験の準備手順

これは試験手順書であり、現場受入完了・実CSV接続完了の記録ではない。自動テストは架空データを使用する。人による受入結果・担当者・実施日・不備は別途記入する。

[2026-11-10の開発環境試行記録](development-rehearsal-2026-11-10.md)に、本日付の架空キットによるAPI自動試行と、画面操作ツールのエラーで未確認となった範囲を記録した。下表の現場結果を代替しない。

## 実施前

- 業務設定、確認者、現物在庫手順、期限・積載条件を責任者が確定する。未確定事項は`open-questions.md`参照。
- 実データ・既存DBを上書きしない試験環境を用意する。試験で発行した帳票は実出荷に使用しない。
- サンプル日は2026-11-09。UIの正式発行は本日のみなので、日付が異なる場合は固定日付の自動テストと`python -m bunsen.demo`でロジックを検証する。実日付での受入には責任者が確認した試験データを用意する。
- 架空操作試験は[受入キット](acceptance-kit.md)で指定日サンプルを生成できる。同じ`--trial-kit`で再起動し通常履歴から隔離する。実データの業務照合は代替しない。
