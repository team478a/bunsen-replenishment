# エラーメッセージの読み方

## 需要予測が足りない場合

例：予測CSVが12/2までで、神戸12/4・杉戸12/5までの予測が必要だった場合。

```text
需要予測が足りないため、計算できません

現在の補充条件で計算するには、次の期間の需要予測が必要です。
・ムロオ神戸：2026-12-03〜2026-12-04の予測が不足（対象の商品数を表示）
・ムロオ杉戸：2026-12-03〜2026-12-05の予測が不足（対象の商品数を表示）

対処方法：
不足期間を含む予測CSVを取り込み直し、「データを開いて計算」を押してください。
```

同じ倉庫・同じ不足期間はまとめます。商品ごとに期間が違えば別々に表示します。途中の日付が抜けている場合も、その不足期間を表示します。安全在庫の日数は、今回の補充でまかなう期間の後に追加されます。エラー回避のために設定値を変えたり、未取得の予測を0や別日の数量で埋めたりしないでください。

件数が多い場合もメッセージを画面外まで並べず、日常画面の「計算根拠・取込情報」を自動で開きます。「対象の一覧（省略なし）」でJAN・商品コード、倉庫、日付、ファイル、行、項目を確認できます。問い合わせ時は、その下の「問い合わせ用の詳細」も利用できます。

## その他のエラー

- 在庫と出荷の日付が合わない：在庫集計日・出荷日・倉庫の到着までの日数を確認します。
- 出荷日より後に作成された予測：予測の作成日と対象日を区別し、出荷日に適した原本を取り込みます。
- 未確定の予測：正式指示には確認済みの予測が必要です。
- ファイルが見つからない：移動・削除の有無を確認し、ファイルを選び直します。
- 読み書きできない：開いているExcel/PDF、保存先の接続・空き容量・権限を確認します。

表示の改善であり、計算・検証条件・確定可否・取込証跡・過去履歴の意味は変えません。確認が必要な状態では引き続き処理を止めます。旧方式や分類のない個別エラーでは、元の業務メッセージを残して詳細へ案内します。
